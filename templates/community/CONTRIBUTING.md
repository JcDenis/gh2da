# Contributing

Contributions are welcome: issues, ideas and pull requests. You can write in English or French.

## Pull requests

* Target the default branch (`master`).
* One subject per pull request, with a short description and how to test it.
* Code must work with the Dotclear version required in `_define.php` and pass the checks
  run automatically on each pull request (PHP lint and PHPStan level max).
* Follow existing code style (Dotclear coding standards, typed code, `Helper\Html\Form` for forms).
* Do not change version numbers, they are set at release time.

## Releases

Releases are done by the maintainer with the release button of the workflow "Dotclear module".
